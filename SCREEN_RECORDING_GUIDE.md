# CampusBite Screen Recording Guide

The project does not include a fabricated recording. Record your own run of the app after starting it with `npm run dev`.

## Demo checklist

1. Open the application and point out the CampusBite menu.
2. Search for a food item, then clear the search.
3. Select a category and show the filtered results.
4. Open a dish to show its details, ingredients, and availability.
5. Add it to your bag and increase its quantity.
6. Show the updated cart badge in the navigation.
7. Open the bag and show the updated quantity and total.
8. Remove an item, then add a dish again if needed.
9. Navigate to checkout and briefly show the simulated-order note.
10. Submit valid student and pickup details.
11. Show the order number and confirmation summary.

## Windows Snipping Tool

1. Start CampusBite with `npm run dev` and open the Vite URL in your browser.
2. Open Snipping Tool from the Start menu.
3. Choose **Record**, select **New**, and drag around the browser area.
4. Select **Start**, perform the checklist, then select **Stop**.
5. Review the recording and save it to the location required by your course.

## OBS Studio

1. Install and open OBS Studio.
2. Add a **Window Capture** source for your browser (or **Display Capture** if needed).
3. Confirm the preview shows CampusBite and your microphone/desktop audio settings are correct.
4. Select **Start Recording**, perform the checklist, then select **Stop Recording**.
5. Use **File → Show Recordings** to find the saved video.

Keep personal information private in the recording. Use sample student/contact details only; the checkout is simulated and does not submit them to a service.
